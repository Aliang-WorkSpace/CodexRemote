# Codex Remote 使用说明

`Codex Remote` 是 `Codex` 的 iPhone 副控端。

它的定位不是替代 Mac 主控台，而是让你在离开工位时，继续：

- 查看这台 Mac 当前的总览状态
- 接管等待输入的会话
- 重试失败任务
- 跟进最近命令和事件轨迹

## 使用顺序

1. 在 Mac 上启动 `Codex Remote` 控制台服务
2. 确认 iPhone 和 Mac 在同一个 Wi-Fi
3. 在 iPhone 上连接主控 Mac
4. 先看首页总览，再看焦点任务和待处理队列
5. 进入会话详情继续发送提示词，或执行继续/重试/停止

## 最小连接步骤

如果你只是想尽快连上，一共只需要 3 步：

1. 在 Mac 上启动 `Codex Remote`
2. 让 iPhone 和 Mac 连接同一个局域网 / Wi-Fi
3. 在 iPhone 里点击“直接接入这台 Mac”，或填写 Mac 的局域网地址

如果连接失败，先回到 Mac 检查本地控制台服务是否已经启动。

## 连接方式优先级

1. 恢复已信任设备
2. 接入自动发现到的附近 Mac
3. 从剪贴板快速导入
4. 手动输入地址
5. 手动输入一次性配对码

## 首页怎么看

- `总览`：看运行中、待接管、异常、自动化
- `任务焦点`：系统自动选出当前最值得优先处理的会话
- `待处理队列`：快速决定下一步先接哪一个
- `会话列表`：需要时再展开查看全部会话

## 会话详情怎么看

- `运行概览`：当前会话状态、模型、更新时间
- `操作区`：继续发送提示词、继续运行、重试运行、停止运行
- `最近命令`：查看刚刚执行过什么、成功还是失败
- `事件时间线`：理解当前执行轨迹和异常原因

## 常见状态

- `等待输入`：最适合人工接管，通常优先级最高
- `执行中`：Mac 正在运行，先观察，不一定要立即干预
- `排队中`：命令已提交，等待处理
- `异常`：建议先看最近命令和事件，再决定是否重试

## 隐私与数据

- Codex 进程和工作区保留在 Mac 上
- iPhone 只作为副控端，不直接承载执行上下文
- 当前主要以局域网/可信设备恢复为主
